## 📝 أمثلة

### Lisp الأساسي:

    (اطبع "السلام عليكم")
    (تعريف مربع (لامدا (ن) (* ن ن)))
    (اطبع (مربع 5))

### FORTRAN (علمي):

    (اطبع (مساحة_مثلث 10 6))
    (اطبع (جيب 0))
    (اطبع (باي))

### BASIC (تعليمي):

    (اطبع (كرر_من_إلى 1 5))
    (اطبع (طول_نص "السلام"))
    (اطبع (يسار "السلام" 3))

### SQL (بيانات):

    (أنشئ_جدول "طلاب" (قائمة "اسم" "عمر"))
    (أدرج "طلاب" "اسم" "محمد")
    (اعرض "طلاب")

### COBOL (أعمال):

    (ريال 3500)
    (ضريبة 10000)
    (ربح 2500 3500)

## 🔐 مكتبة التشفير — crypto.py

| الدالة | الوصف |
|--------|-------|

| تحقق_hmac | التحقق من التوقيع |
| ترميز_base64 | UTF-8 إلى Base64 |
| فك_base64 | Base64 إلى UTF-8 |
| مفتاح_عشوائي | توليد مفاتيح آمنة |
| مقارنة_آمنة | مقارنة constant-time |
| بصمة_سلسلة | بصمة موحدة |
| تشفير_xor | تشفير XOR |
| فك_xor | فك XOR |

**أمثلة:**
    (بصمة_نص "لسان قريش")
    (ترميز_base64 "قريش")
    (تشفير_xor "لسان" "سر")
