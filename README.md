## الاستخدام

    quraysh              # المفسر التفاعلي
    quraysh file.lisp    # تشغيل ملف

## المزايا

- قواعد عربية أصيلة (ألّم، انقص، جَلَد)
- رموز مختصرة (+, -, *, /)
- دعم الأرقام العربية (٥ ← 5)
- عمليات مكارثي (أوّل، بَقِيَّة، ضُمَّ، واحِد)
- رياضيات (جذر، مطلق، قوة، زوجي، فردي)
- شروط (إنْ)

## 🔒 الميزات الأمنية

- **العقد الأمني** — كل ملف يعلن عملياته
- **الصندوق الزجاجي** — محاكاة قبل التنفيذ
- **الموافقة** — لا تنفيذ بدون إذن
