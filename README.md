## 📝 أمثلة

### Lisp الأساسي:

    (اطبع "السلام عليكم")
    (تعريف مربع (لامدا (ن) (* ن ن)))
    (اطبع (مربع 5))

### FORTRAN (علمي):

    (اطبع (مساحة_مثلث 10 6))
    (اطبع (جيب 0))
    (اطبع (باي))

### BASIC (تعليمي):

    (اطبع (كرر_من_إلى 1 5))
    (اطبع (طول_نص "السلام"))
    (اطبع (يسار "السلام" 3))

### SQL (بيانات):

    (أنشئ_جدول "طلاب" (قائمة "اسم" "عمر"))
    (أدرج "طلاب" "اسم" "محمد")
    (اعرض "طلاب")

### COBOL (أعمال):

    (ريال 3500)
    (ضريبة 10000)
    (ربح 2500 3500)
