## 🛡️ فحص المنافذ الأخلاقي (Ethical Port Scan)

أداة `qur-intel` تدعم فحص المنافذ المفتوحة، مع تنبيه أخلاقي وقانوني في حال اكتشاف منافذ خطيرة.

### الأمر:
PYTHONPATH=src python3 tools/qur-intel/main.py ports example.com

### ماذا تفعل؟
- تفحص المنافذ الشائعة (21, 22, 23, 25, 53, 80, 110, 135, 139, 143, 443, 445, 993, 995, 1433, 3306, 3389, 5900).
- تطبع المنافذ المفتوحة.
- تنبهك إذا وجدت منافذ خطيرة (RDP, VNC, MSSQL, MySQL, FTP).
- تذكرك بالإبلاغ الفوري عبر cert@nca.gov.sa.

### تنبيه:
استخدم هذه الميزة فقط على نطاقات تملكها أو لديك تصريح رسمي بفحصها.
